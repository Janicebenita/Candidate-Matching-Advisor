# Candidate Matching Advisor

An explainable recruiting assistant that maps candidate evidence to approved job criteria.

## Workflow

1. Receive the role profile and candidate materials.
2. Map evidence to essential and preferred criteria.
3. Record matches, gaps, and unresolved questions.
4. Present a non-binding summary for recruiter review.

## Passport Files

The root folder contains all three required OpenGAP passport files.
